Fix “No compatible devices found” (do in order):
  1. Plug Arduino via USB. Check Windows Device Manager → Ports (COM & LPT) shows USB-SERIAL / CH340 / CP210x. Nothing there = cable or driver issue.
  2. Install CH340 driver (cheap Nanos need it), try another cable — most phone cables are charge-only and never show a port.
  3. Use Chrome / Edge / Brave on laptop (not phone, not Firefox). Open via http://localhost or http://127.0.0.1 (you already do — good).
  4. Close Arduino IDE Serial Monitor — only one program can hold the port.
  5. Press buttons 1 → 100 in order, 2 sec apart, IR LED pointed at TV bottom bezel. #1 is verified Panasonic POWER — if #1 does nothing, suspect wiring/aim, not codes.
